English is now the primary documentation language.

Read the **[Xskin README](README.md)** for features, installation, supported media, interface languages, privacy, system requirements, and development instructions.

macOS 1.8.3 / Windows 1.8.2 add long-history usage recovery, waiting/reconnecting states and native translucent materials. The final review removes duplicate tail reads and makes stylesheet validation wait through updates. [Review and validation limits](docs/release-1.8.3-review.md).

[Windows 1.8.2](https://github.com/timmyc07/Xskin/releases/tag/windows-v1.8.2) · [macOS 1.8.3](https://github.com/timmyc07/Xskin/releases/tag/v1.8.3) · [User guide](docs/background-panel.md)

macOS 1.8.3 supports opening the **official Codex app**: its enabled login service gracefully reopens each fresh ordinary launch once to apply the saved background while Xskin stays closed. Windows 1.8.2 keeps **Codex (Xskin)** shortcuts and never automatically closes/reopens Codex. Paused/existing sessions are skipped. Both versions place usage above the input and reveal the wallpaper through translucent input/toolbar surfaces. [Migration, actual validation and authorization status](docs/direct-launch-shortcut.md).

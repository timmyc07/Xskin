# Xskin

English is the primary documentation language. Read the **[Xskin README](README.md)** for features, installation, supported media, privacy, system requirements, and development instructions.

The README includes five maintainer-provided macOS screenshots: two background styles, the [in-Codex preview and settings](README.md#preview-and-tune-inside-codex), and the [conversation usage strip above the input](README.md#leave-room-around-the-input). Screenshot values are examples, not live account status.

[Windows 1.8.5](https://github.com/timmyc07/Xskin/releases/tag/windows-v1.8.5) · [macOS 1.9.4](https://github.com/timmyc07/Xskin/releases/tag/v1.9.4) · [macOS plugin](https://github.com/timmyc07/Xskin/releases/download/v1.9.4/xskin-plugin-v1.9.4.zip) · [User guide](docs/background-panel.md)

**macOS / plugin 1.9.4:** open **More → Xskin** to choose, preview, and apply media. If no background connection is available, enable **Apply when official Codex opens**, fully quit Codex, then reopen the official app; the fresh launch gracefully reopens once to connect. Opening the panel alone does not enable that service. See [installation, connection requirements, and validation limits](docs/in-app-studio.md).

**Windows 1.8.5:** use the standalone app and **Codex (Xskin)** shortcuts. Windows has no embedded Xskin panel and never automatically closes/reopens Codex. See [platform startup and recovery](docs/direct-launch-shortcut.md).

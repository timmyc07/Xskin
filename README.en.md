macOS 1.8.4 / Windows 1.8.3 recover stalled usage connections without restarting Codex. macOS also repairs direct-entry watchers, detects rebuilt runtimes and recovers interrupted applies. [Scenario coverage and remaining limits](docs/macos-reliability.md).

[Windows 1.8.3](https://github.com/timmyc07/Xskin/releases/tag/windows-v1.8.3) · [macOS 1.8.4](https://github.com/timmyc07/Xskin/releases/tag/v1.8.4) · [User guide](docs/background-panel.md)

macOS 1.8.4 supports opening the **official Codex app**: its enabled login service gracefully reopens each fresh ordinary launch once to apply the saved background while Xskin stays closed. Windows 1.8.3 keeps **Codex (Xskin)** shortcuts and never automatically closes/reopens Codex. Paused/existing sessions are skipped. Both versions place usage above the input and reveal the wallpaper through translucent input/toolbar surfaces. [Migration, actual validation and authorization status](docs/direct-launch-shortcut.md).

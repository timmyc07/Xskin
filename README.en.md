The unreleased macOS 1.8.3 / Windows 1.8.2 source adds long-history usage recovery, waiting/reconnecting states and shared translucent menus/settings/page materials. [Coverage and validation](docs/surface-materials.md). Published packages below remain unchanged. The native-header follow-up also handles native surface colors and sticky-header decoration; actual official-route visual validation is still pending.

[Windows 1.8.1](https://github.com/timmyc07/Xskin/releases/tag/windows-v1.8.1) · [macOS 1.8.2](https://github.com/timmyc07/Xskin/releases/tag/v1.8.2) · [User guide](docs/background-panel.md)

macOS 1.8.2 supports opening the **official Codex app**: its enabled login service gracefully reopens each fresh ordinary launch once to apply the saved background while Xskin stays closed. Windows 1.8.1 keeps **Codex (Xskin)** shortcuts and never automatically closes/reopens Codex. Paused/existing sessions are skipped. Both versions place usage above the input and reveal the wallpaper through translucent input/toolbar surfaces. [Migration, actual validation and authorization status](docs/direct-launch-shortcut.md).

# Xskin

English is the primary documentation language. Read the **[Xskin README](README.md)** for features, installation, supported media, privacy, system requirements, and development instructions.

The README includes two maintainer-provided [Windows screenshots](README.md#windows-in-action) showing different full-window backgrounds on Codex Home, alongside five macOS screenshots: two background styles, the [in-Codex preview and settings](README.md#preview-and-tune-inside-codex), and the [conversation usage strip above the input](README.md#leave-room-around-the-input). The pictured media are not bundled wallpapers. Screenshot values are examples, not live account status.

[Windows 1.8.5](https://github.com/timmyc07/Xskin/releases/tag/windows-v1.8.5) · [macOS 1.9.4](https://github.com/timmyc07/Xskin/releases/tag/v1.9.4) · [macOS plugin](https://github.com/timmyc07/Xskin/releases/download/v1.9.4/xskin-plugin-v1.9.4.zip) · [User guide](docs/background-panel.md)

**macOS / plugin 1.9.4:** open **More → Xskin** to choose, preview, and apply media. If no background connection is available, enable **Apply when official Codex opens**, fully quit Codex, then reopen the official app; the fresh launch gracefully reopens once to connect. Opening the panel alone does not enable that service. See [installation, connection requirements, and validation limits](docs/in-app-studio.md).

**Windows source 1.9.4:** now mirrors the macOS embedded studio, original-media previews, recovery, six presets and opt-in official-launch background service. The standalone Flutter panel and Codex (Xskin) shortcuts remain available. Build both Windows packages with the [Windows guide](windows/README.en.md); see [parity and validation](docs/windows-parity.md). The download above remains the previous published 1.8.5 release until a new release is published.

# Xskin for Windows

[Download Windows 1.6.0](https://github.com/timmyc07/Xskin/releases/tag/windows-v1.6.0)

The current 1.7.0 source adds automatic first-use setup, a per-user logon task for saved backgrounds and a token/cache overlay. Packaged builds include `Install Xskin.exe`; opening `xskin.exe` directly also initializes setup once. Node.js is bundled, so packaged users do not need a separate Node or Flutter installation. The published download remains 1.6.0 until a new release is published.

See the [Windows Flutter guide](README.md) for installation, image and MP4 previews, controls, build instructions, verification and recovery.
